# APIbancaria

# 🏦 API Bancária Simulada em Python  
Um projeto simples e didático que simula operações bancárias em Python, utilizando POO, boas práticas e interatividade via terminal.

---

## 🚀 Funcionalidades

A API implementa operações básicas de um sistema bancário:

- Criar conta bancária  
- Listar contas  
- Depositar dinheiro  
- Realizar saques  
- Transferência entre contas  
- Validações de erros (saldo insuficiente, conta inexistente, valores inválidos etc.)
